# Saved acoustic categories

The read-only acoustic helper names the six categories saved with a fitting: earpiece, hook, vent, tubing, acoustic fitting level and fitted side. It accepts the researched Intent 3 profile only: HIID 4.5, release package 5.0.29 and runtime map 10.0.0, using identity from the same verified archive.

These are explicit wire codes. Their numbers do not describe the positions of choices in Genie's filtered, sorted lists. The helper returns the original code, a stable symbolic identifier and an independently written English category label. An unrecognized code keeps its number and has no invented name. An explicit unspecified value remains distinct from a recorded `None` or closed vent.

**Names describe saved fitting categories. They do not verify the parts currently fitted. Receiver variant, dome size, wire length and acoustic compatibility require additional information.**

In particular:

- A stored acoustic fitting level is not a measured output or a verified receiver model.
- Vent names describe nominal categories. They do not report a measured vent or its modelled equivalent diameter.
- Physical style, hearing-instrument interface, attachment method and receiver/module state affect valid combinations and some display variants. These are not all present in the six saved bytes.
- A recorded left/right value describes the saved fitting. It does not independently establish the connected aid's identity.

The helper contains independently authored logic, wire enumeration facts and original labels. It ships no vendor model documents, UI resources, acoustic curves, factory presets or calculation engine. Its fixtures are synthetic; actual device codes and fitting data remain private.
