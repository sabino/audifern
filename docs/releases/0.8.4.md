# Audifern 0.8.4

Audifern opens in a smaller 1120 × 860-point window, with a narrower default
sidebar. Existing saved window sizes remain respected.

- Refreshed screenshots show the current interface at a compact, readable size.
- The README focuses on installation, everyday features and where to find help.
- A user guide and documentation index separate everyday guidance from technical research.
- Shared Help exports provide the app's translated guidance for the website,
  without treating the README as a manual.

Existing device artwork and the canonical Audifern mark are preserved. This
release changes presentation and documentation; hearing-aid commands are unchanged.
