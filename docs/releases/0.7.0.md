## Fitting workbench and private backups

- Explore recovered listening programs, adaptation, processing and gain/MPO
  parameter tables in **Fitting → Saved fitting**.
- Inspect fitting software version, stored rationales and tagged audiogram
  snapshots without connecting to the aids. Stored units and original exam
  dates remain unknown; local dB HL review requires external confirmation.
- Prepare a separate local plan with context, per-ear acoustics, a linked exam,
  supported rationale/adaptation preferences and program ideas.
- Preserve readable state in verified, private, immutable backups. Completed
  reads are saved incrementally; interrupted captures are labeled as partial.
- Enter 750 Hz and 1500 Hz audiogram values and use the editor in narrower
  windows. New tools are translated into English, Brazilian Portuguese and
  Spanish and follow the app’s appearance preference.

Direct read-only acquisition was checked on one Intent 3 pair with release
5.0.29, HIID 4.5 and memory map 10.0.0. Each aid returned its fitting-system
record and all 25 advertised persisted end-user-setting scopes. Other profiles
are preserved without guessing their parameter layout.

These changes do not implement clinical fitting writes, audiogram-to-gain
calculation, new on-device programs, calibrated measurements, clinical restore
or firmware updates. Gain tables show raw parameter coordinates, not calibrated
acoustic responses. See the [backup guide](../fitting-backups.md) and
[feature map](../genie-feature-map.md) for coverage and remaining work.
