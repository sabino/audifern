Audifern downloads are now **Developer ID signed and Apple-notarized**.

- Hardened runtime and secure signing timestamps.
- Apple notarization tickets attached to the universal app and DMG, including
  the copy inside the ZIP.
- GitHub independently checks both CPU slices, signatures, tickets, Gatekeeper
  acceptance, checksums and source provenance before publishing.
- Apple credentials and the private signing key stay in the maintainer's Mac
  Keychain; GitHub receives only the signed downloads.

Open the DMG and drag Audifern to Applications, then allow Bluetooth access.
Requires macOS 14 or later on Apple Silicon or Intel.

Hearing-aid controls are unchanged from 0.6.0. Advanced UTL authentication is
provisioned locally by the device owner and is excluded from downloads.
Fresh pairing, other hearing-aid models and long-term reliability need further
testing. See the README and hardware verification notes for current limits.
