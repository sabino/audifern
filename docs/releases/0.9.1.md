# Audifern 0.9.1

- Fixed Malt installations intermittently appearing as “Installation not identified” in Updates & changelog. If a read-only database receipt is unavailable, Audifern now checks Malt’s CLI receipt for the exact installed app.
- An unreadable receipt or failed executable no longer prevents checking another available receipt. Unresolved ownership still disables in-app installation, and Malt and Homebrew installations continue to use their package manager.
