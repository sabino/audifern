## Clearer sound controls

- Improve white-label contrast on green filled controls in dark mode while
  retaining the adaptive accent for ordinary text and icons.
- Separate the title-bar connectivity and Settings actions. Center the EQ
  Together/Separate selector beneath the master grouping selector.
- Remove More sound controls from inline EQ. Restore sound defaults now sits
  directly underneath, with Reset EQ beside Apply. Dedicated streaming-source
  gain remains available through Source volume.
- Add device-reported volume bounds, per-step ticks and a clearly positioned
  zero marker. The scale handles asymmetric ranges such as -8 through +3.
- Keep narrow translated layouts within the window, using native popup choices
  when segmented controls will not fit. Add a native preview of the revised Sound controls.

The full local Swift test suite, localization and canonical-brand checks pass.
Native UI verification uses synthetic demo devices; this update does not add a
new physical hearing-aid audio test or change the Bluetooth protocol.

Downloads are universal for Apple Silicon and Intel on macOS 14 or later, signed
with Developer ID and Apple-notarized by the protected release workflow.
