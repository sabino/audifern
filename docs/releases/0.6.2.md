Audifern releases now sign and notarize entirely in GitHub Actions.

- Version tags dispatch the trusted workflow on main. The workflow verifies the
  maintainer's GPG signature, main ancestry, version and immutable source commit.
- Apple credentials are restricted to a main-only GitHub environment. A temporary
  Keychain holds only the expected Developer ID identity and is removed before
  release artifacts are uploaded.
- Both the app and DMG are notarized and stapled. A fresh Mac runner independently
  verifies signatures, tickets, Gatekeeper, CPU slices, source links and checksums
  before publication.
- PR builds cannot access the signing environment. Published releases and tags
  are preserved.

Hearing-aid controls are unchanged. Requires macOS 14 or later, on Apple Silicon
or Intel. Open the DMG and drag Audifern to Applications, then allow Bluetooth.
Advanced hearing-aid authentication is provisioned locally and is not included.
